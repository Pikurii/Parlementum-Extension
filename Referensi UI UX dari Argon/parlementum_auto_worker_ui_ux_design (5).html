Kode Produksi HTML & CSS: Netral OFF Badge & Settings Collapse

Memperbaiki warna badge OFF menjadi abu-abu netral serta collapse sub-panel Permukaan C

1. CSS: Collapsed Card Min-Height & Neutral Badge CSS3 Refinement 
/* Kartu Collapsed dengan padding proporsional & min-height */
.paw-card.collapsible-card.collapsed {
  min-height: 44px;
  padding: 10px 14px !important;
}

/* Badge Netral OFF vs Active Hijau */
.badge-train-off {
  background: rgba(255, 255, 255, 0.06);
  border: 1px solid rgba(255, 255, 255, 0.12);
  color: #94a3b8;
}
2. JS: Toggle Settings Sub-Panel Hidden/Visible Progressive Disclosure 
// Saat OFF di Permukaan C, sub-panel otomatis disembunyikan
if (botState.statsTrainingActive) {
  settingsStatsWrapper.classList.remove('hidden');
  settingsOffBanner.classList.add('hidden');
} else {
  settingsStatsWrapper.classList.add('hidden');
  settingsOffBanner.classList.remove('hidden');
}
