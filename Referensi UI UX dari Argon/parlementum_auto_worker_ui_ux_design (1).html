Kode Produksi HTML & CSS: Stat Card Checkbox & Dimming System

Siap diintegrasikan langsung ke dalam ekstensi browser Parlementum Auto Worker

1. Styling CSS (.stat-card.active vs .stat-card.dimmed) CSS3 Glassmorphism 
/* Kartu Stat Modular dengan Transisi Halus */
.stat-card {
  background: rgba(22, 27, 42, 0.75);
  backdrop-filter: blur(16px);
  border: 1px solid rgba(255, 255, 255, 0.08);
  border-radius: 12px;
  transition: opacity 0.28s cubic-bezier(0.16, 1, 0.3, 1),
              filter 0.28s cubic-bezier(0.16, 1, 0.3, 1),
              border-color 0.28s ease, box-shadow 0.28s ease;
}

/* Status Aktif (Dicentang): Menyala Penuh + Glow Tema */
.stat-card.active {
  opacity: 1;
  filter: grayscale(0%);
}
.stat-card.active.theme-str {
  border-color: rgba(244, 63, 94, 0.45);
  background: radial-gradient(circle at 50% 0%, rgba(244, 63, 94, 0.12), transparent 70%),
              rgba(22, 27, 42, 0.85);
  box-shadow: 0 8px 24px -6px rgba(244, 63, 94, 0.18);
}

/* Status Nonaktif (Tidak Dicentang / Dimmed): Redup & Terkunci */
.stat-card.dimmed {
  opacity: 0.42;
  filter: grayscale(65%);
  border-color: rgba(255, 255, 255, 0.06);
  background: rgba(13, 17, 28, 0.65);
  box-shadow: none;
}

Rekomendasi Arsitektur Visual & Spesifikasi CSS

1. Palet Warna & Glassmorphism

Menggunakan kanvas dasar #0a0e1a dengan kartu modular rgba(22, 27, 42, 0.75), backdrop-filter: blur(16px), serta garis tepi 1px solid rgba(255,255,255,0.08) yang menyala sian saat di-hover.

2. Tipografi Anti-Getar (Tabular-Nums)

Seluruh teks body minimal 12px dan angka metrik 13px–20px dengan font-variant-numeric: tabular-nums pada JetBrains Mono agar detik timer hitung mundur tidak pernah bergeser secara horizontal.

3. Ikonografi Vektor Murni (Zero-Emoji)

Seluruh indikator menggunakan SVG garis vektor bergaya Lucide/Feather (stroke-width: 1.75px) dengan titik status CSS berdenyut (pulseRing) yang tajam di semua resolusi monitor.
