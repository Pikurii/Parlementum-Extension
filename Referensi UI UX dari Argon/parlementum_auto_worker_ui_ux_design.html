Rekomendasi Arsitektur Visual & Spesifikasi CSS

1. Palet Warna & Glassmorphism

Menggunakan kanvas dasar #0a0e1a dengan kartu modular rgba(22, 27, 42, 0.75), backdrop-filter: blur(16px), serta garis tepi 1px solid rgba(255,255,255,0.08) yang menyala sian saat di-hover.

2. Tipografi Anti-Getar (Tabular-Nums)

Seluruh teks body minimal 12px dan angka metrik 13px–20px dengan font-variant-numeric: tabular-nums pada JetBrains Mono agar detik timer hitung mundur tidak pernah bergeser secara horizontal.

3. Ikonografi Vektor Murni (Zero-Emoji)

Seluruh indikator menggunakan SVG garis vektor bergaya Lucide/Feather (stroke-width: 1.75px) dengan titik status CSS berdenyut (pulseRing) yang tajam di semua resolusi monitor.
